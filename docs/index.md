# MosaicJS

MosaicJS is a lightweight, event-driven drag-and-drop engine designed for the
WhittakerTech ecosystem. It provides:

- snapshot + rollback mechanics
- constraint-driven drop validation
- a simple event API
- predictable states backed by full test coverage

This is the v0.1 documentation. Drag behavior will expand in v0.2 with hover
target detection and drop heuristics.
